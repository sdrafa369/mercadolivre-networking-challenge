# Mercado Livre - Networking

Laboratório Networking Mercado Livre 

Projeto de automação Cisco utilizando PnetLab, Python, Netmiko e Tkinter.

## Tecnologias
- PNETLAB
- Python
- Netmiko
- Tkinter
- Cisco IOS
- GitHub Desktop

## Objetivo
Automatizar:
- criação de VLANs
- alteração de hostname
- backup
- validação de configuração
