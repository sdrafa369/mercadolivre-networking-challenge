# Mercado Livre - Networking

Laboratório de Candidatos Networking Mercado Livre 

Projeto de automação Cisco utilizando Python, Netmiko e Tkinter.

## Tecnologias
- Python
- Netmiko
- Tkinter
- Cisco IOS

## Objetivo
Automatizar:
- criação de VLANs
- alteração de hostname
- backup
- validação de configuração
